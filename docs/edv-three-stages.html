Evidence-Driven Validation: three ways to build it

The rules barely changed between these stages. What changed is who applies them — and whether they can be skipped.

Stage 1 · original MedRAX

Trust the model

Who judges the evidence? GPT-4o, unconstrained

  • Raw tool output goes straight back to the model, untouched
  • Prompt is six lines: “solve using your own vision … tools complement your reasoning”
  • The model is the primary reader; specialists are a supplement
  • Confidence is whatever the model says it is

Fails whenThree tools near 0.50 outvote one specialist at 0.95. Nothing notices, and nothing in the output shows it happened.

Stage 2 · EDV as a prompt

Ask the model

Who judges the evidence? GPT-4o, instructed

  • A long rubric written in English: consult ≥2 tools, quote every number, never omit a tool that disagrees
  • “A probability near 0.50 expresses no opinion — do not count it as a vote”
  • Confidence rubric with fixed bands: 0.30–0.70 caps you at Medium
  • The model also supplies the visual evidence, from its own reading

Fails whenIt is a request, not a rule. The model can skip a step or count that 0.50 anyway — and you cannot tell from the output whether it complied. The bands are guesses.

Stage 3 · EDV as code

Compute it

Who judges the evidence? Python, before the model sees anything

  • Every tool result is intercepted; the verdict is arithmetic, no AI involved
  • Thresholds are measured per tool and per finding, not assumed at 0.5
  • Strength = margin × (AUC−0.5) × 2, and the ceiling takes the strongest single tool — never a sum, so agreement cannot outvote quality
  • Visual evidence comes from CheXagent’s boxes, not from the generalist

Still openThe model can still invent detail in prose. A computed ceiling constrains stated confidence — it cannot make a sentence true.

How this compares to CXRAgent (arXiv:2510.21324), where the term EDV originates. Its paper states the validator “does not rely on a secondary, task-specific vision model … it is implemented as a high-level reasoning protocol executed by the central multi-modal LLM.” Their code agrees — EDV is a system prompt asking the LLM to restate each conclusion with supporting evidence, refuting evidence and a credibility judgement. That is Stage 2. This work takes it to Stage 3, and deliberately inverts one choice: it does use a second vision model for evidence, because the generalist’s own reading was measured to do harm.
