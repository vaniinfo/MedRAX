Evidence-Driven Validation

Is there a meaningful observation? → How trustworthy is this particular observation? → How much independent corroboration exists? → What has that evidence level actually meant on unseen data? There is no voting anywhere in the chain.

Why not counting

Two runs, visually identical tool agreement — both experts answering yes at 0.96–1.00 — and 2.3× the evidential weight. Every input to the difference is measured.

Both claims were correct. The atelectasis one was reported at low confidence because both tools are poor at asserting it and their errors coincide; a vote-counting system would have called two-for-two overwhelming.

Three tools agreeing raises the anchor by 0.11, because their errors coincide.

Calibration figures are scoring-dependent. These are for evidence strength scored on directional reliability. An earlier version scored graded tools on margin × discrimination and reported 52.5% / 67.6% / 87.8% across three bands, separating only the highest from the lowest. Moving to directional reliability compressed the scale: nothing reaches 0.80, but the 0.48 boundary became established. Any change to evidence strength invalidates this box and requires re-running scripts/calibrate_claims.py.

What is no longer in the path

A guessed dead zone. A fixed 0.5 decision point. A model-level reliability score. Margin credit for a model that answers in absolutes. Corroboration credit for models that fail on the same films. And a confidence grade chosen by anyone's judgement.

Limits

Pneumothorax is unvalidated — the corpus holds 28 positives and the fitting set took all of them. Ground truth is report-derived MeSH rather than an independent read. Error dependence is measured pairwise, which does not fully describe the joint error structure of three tools. External validation is obstructed by the tools having trained on most public CXR data: SIIM-ACR was ruled out on finding NIH's corrupted ages, 148 and 413, in its metadata.
